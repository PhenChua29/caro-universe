## Brief

This a project that served my educational purpose that I made by myself while learning Java courses in FPT University.

Feel free to grab the [.jar file](https://github.com/PhenChua29/caro-universe-v2/releases/download/v1.1/CaroUniverse.jar) and enjoy it ~

## Features
- Simple yet thrilling gameplay with 3 difficulty levels: Easy, Medium, and Hard
- Randomized player and bot avatars. Each new game, you face a different bot with a unique identity
- Clean space-themed design with cute characters
- Climb the leaderboard and become the top player
